# 수행 내용과 기여 범위

프로젝트에서 수행한 기술 작업을 정리한다. NVIDIA 기반 모델을 새로 개발했거나 범용 주행 제어를 완성했다고 주장하지 않는다. 공동 작업·AI 도구의 도움을 포함한 실제 역할은 발표자가 최종 확인해야 한다.

## 문제 정의

철도처럼 보이는 영상과 원하는 이동 조건을 따르는 영상을 구분했다. 정지·정속·가감속, 시점, 선로 구조를 나눠 결과를 읽는 기준을 마련했다. 텍스트 조건과 카메라 Action 조건은 다른 연구 단계로 기록한다.

## 데이터·학습 설계

Isaac Sim의 RGB·pose를 연결하고 프레임 간 상대 변환을 9D Action으로 구성했다. 실제 취득 pose와 촬영 설정에서 재구성한 pose는 신뢰 수준을 구분한다. 실사 pose가 없는 영상에 임의 Action을 정답으로 붙이지 않고 domain 적응 데이터로 사용했다.

공통 철도 초기값을 계승한 domain → FD 단계와 가상 전용/실사 혼합 비교를 구성했다. 생성부 LoRA와 camera 입력 projector의 학습 범위를 구분하며 backbone 전체 학습으로 설명하지 않는다.

## 운영·개발 산출물

입력·prompt·seed·checkpoint·sampling 설정을 보존하고 모델 로딩 확인과 의미적 성공을 구별했다. 기존 가중치를 불러오는 CLI, 입력 계약 검사, tensor hash 대조, 전체 영상 디코딩 검사, 작업 상태·로그 조회를 구현하고 확인했다.

## 기존 기술과의 경계

Cosmos backbone·기본 Forward Dynamics 구조·Wan VAE·tokenizer·NVIDIA 프레임워크는 기존 구성요소다. 프로젝트의 개발 대상은 철도 적용을 위한 데이터 처리·학습 설정·실험 운영·추론 및 검증 도구다.

## 면접 설명 예시

“영상이 그럴듯하게 생성되는 것과 원하는 주행 조건을 따르는 것을 분리해서 봤습니다. 시뮬레이터의 카메라 이동값을 영상과 연결하고 기존 모델을 후속학습했으며, 같은 조건의 비교와 명령어 기반 재현 도구까지 정리했습니다. 다만 장면 구조와 정확한 속도 추종은 아직 해결 과제로 남아 있습니다.”
