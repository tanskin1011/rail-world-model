# 결과 정리 — 확인 수준을 구분

## 현재 확보한 근거

최종 B checkpoint와 기존 영상·보고서를 인덱스로 연결한다. 포스터 초안의 “진행 중” 문구는 당시 스냅샷이며 현재 상태로 복사하지 않는다.

| 항목 | 확인된 수준 | 아직 주장할 수 없는 것 |
|---|---|---|
| 최종 B 모델 | 기존 FD_joint300 checkpoint 및 완료된 추론 기록 존재 | A 대비 모든 평가에서 우월 |
| Camera 조건 주입 | 첫 영상 조건과 Action 입력 경로·가중치 확인 기록 존재 | 물리 속도의 정확한 추종 |
| GT 대응 평가 | STOP / accel30 / decel30 기존 결과와 미래188프레임 지표 기록 존재 | 세 조건 전부 제어 성공 |
| 외관/구조 | 기존 보고서가 semantic failures를 명시 | 장면 구조·객체 움직임이 완벽히 유지됨 |
| A/B 포스터 질문 | 비교 설계·분할·학습 범위 근거 존재 | 동일 조건 최종 A/B 결과를 재확인하기 전 인과적 개선 확정 |

## 수치·영상 공개 범위

기존 GT 대응 지표와 원본 영상은 로컬 내부 보고서에 보존한다. 기관 및 데이터 원천의 대외 사용 승인 전에는 구체적인 측정값·영상·시설 이미지를 이 저장소에 배포하지 않는다. 영상 유사도와 주행 제어 정확도를 구별해서 평가하며, 수치를 생략한 것을 성능 검증 완료로 해석하지 않는다.

원본 보고서 상태는 `COMPLETE_GENERATION_METRICS_AND_LIBRARY_DELIVERY_WITH_SEMANTIC_FAILURES`다. 이를 “모든 제어 성공”으로 바꿔 서술하지 않는다. 정확한 원본 위치·SHA-256은 Git 제외 `internal/evidence.json`에 저장한다.

## 포트폴리오의 결과 구성

1. 같은 이미지에 서로 다른 Action을 넣는 입출력 예시.
2. 정지·정속·가감속이 실제로 구분되는지 보여주는 기존 비교 영상.
3. 실사 혼합 A/B의 동일 조건 결과. A 산출물의 실제 근거가 확정되기 전에는 미완료로 표시.
4. 주변 구조·사람 움직임·스캔 품질의 실패 사례와 적용 범위.

영상·스크린샷은 기관 및 원천 자료의 대외 사용 가능 여부 확인 후 별도로 추가한다. 11월 1일 생성한 두 영상은 제외한다.
