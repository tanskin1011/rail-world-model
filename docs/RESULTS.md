# 결과와 한계

## 현재 확보한 근거

동일 입력·Action·seed로 생성한 A/B 영상과 기존 GT 대응 평가를 정리했다. 대표 영상은 [결과 갤러리](MEDIA_GALLERY.md)에서 확인할 수 있다.

현재 선택 모델은 FD500이다. FD300에서 200 updates를 추가해 총500에 도달했으며 loss·gradient 유한값과 체크포인트 저장을 확인했다. 기존 감속 평가 영상 5개는 내부에 보관한다. 아래 A/B·CLI 기록은 FD300 기준이며, 최종모델 선택이 FD500의 성능 우위를 입증하지는 않는다.

| 항목 | 확인된 수준 | 아직 주장할 수 없는 것 |
|---|---|---|
| Rail World Model | 기존 FD_joint300 checkpoint 및 완료된 추론 기록 존재 | A 대비 모든 평가에서 우월 |
| Camera 조건 주입 | 첫 영상 조건과 Action 입력 경로·가중치 확인 기록 존재 | 물리 속도의 정확한 추종 |
| GT 대응 평가 | STOP / accel30 / decel30 기존 결과와 미래188프레임 지표 기록 존재 | 세 조건 전부 제어 성공 |
| 외관/구조 | 기존 보고서가 semantic failures를 명시 | 장면 구조·객체 움직임이 완벽히 유지됨 |
| A/B 포스터 질문 | 동일 조건 STOP·accel10·decel30 결과와 모델/입력 설정 대조 기록 확인 | 한 이미지·seed의 결과로 실사 혼합의 인과적 개선 확정 |

## 제공하는 결과

이 저장소에는 A/B 비교영상 3개, 시뮬레이터 원본/생성 비교영상 1개, 합성 학습 이미지 2개를 포함한다. 기존 GT 대응 수치와 실행 로그는 내부 보관본에 남겨뒀다.

영상 생성과 지표 계산은 완료됐지만 STOP·장면 구조 등에서 실패가 남았다. 내부 보고서 상태는 `COMPLETE_GENERATION_METRICS_AND_LIBRARY_DELIVERY_WITH_SEMANTIC_FAILURES`이며, 원본 위치·SHA-256은 Git 제외 `internal/evidence.json`에 보관한다.

## 비교 범위

1. 같은 이미지에 서로 다른 Action을 넣는 입출력 예시.
2. 정지·정속·가감속이 실제로 구분되는지 보여주는 기존 비교 영상.
3. 실사 혼합 A/B의 동일 조건 결과. STOP·accel10·decel30의 대응 A 결과와 설정 대조를 확인했다. const10은 A 결과가 없어 짝 비교에서 제외했다.
4. 주변 구조·사람 움직임·스캔 품질의 실패 사례와 적용 범위.

맵 원본·모델 가중치·실사 원천 영상은 포함하지 않는다. 자료별 출처와 이용 범위는 [외부 구성요소·권리](../THIRD_PARTY.md)를 참고한다.
