# 공개 전 검토

- [x] 기존 저장소의 개편 브랜치 사용, 과거 commit을 부모로 보존
- [x] Git 원격 쓰기 권한 확인(비밀번호/토큰을 채팅에 전달하지 않음)
- [ ] 우선 private 저장소로 연결
- [x] 사용자가 대표 결과 이미지·영상 게시를 명시적으로 요청. 원본 맵·가중치·전체 실사 클립은 게시 범위에서 제외.
- [ ] 실사 데이터 원천 라이선스와 재배포 조건 확인
- [ ] 프로젝트 코드의 저작권·NVIDIA 파생 코드 고지 및 라이선스 선택
- [x] 현재 배포 후보 트리의 내부 경로·IP·대용량 파일 검사(과거 Git 이력 전체를 점검한 것은 아님)
- [ ] 기존 checkpoint의 외부 배포 권리와 기반 모델 의존성 확인
- [x] 현재 commit 후보의 파일 목록 확인: 선택된 대표 미디어만 포함, 원본 맵·가중치 제외
- [x] 실측 결과·설명용 도식/Action·미완료 기능 구분

코드·문서와 사용자가 게시를 요청한 대표 미디어를 포함한다. 원본 지도·가중치·내부 경로·미공개 측정값은 포함하지 않는다. 기존 저장소의 공개 범위 설정은 변경하지 않았다. 선택된 게시물 외 다른 자산의 배포 권리나 일괄 LICENSE를 임의 부여하지 않는다.
