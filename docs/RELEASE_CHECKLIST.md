# 공개 전 검토

- [x] 기존 저장소의 개편 브랜치 사용, 과거 commit을 부모로 보존
- [x] Git 원격 쓰기 권한 확인(비밀번호/토큰을 채팅에 전달하지 않음)
- [ ] 우선 private 저장소로 연결
- [ ] 기관 지도·시설·로고·영상·연구 수치의 대외 사용 승인
- [ ] 실사 데이터 원천 라이선스와 재배포 조건 확인
- [ ] 프로젝트 코드의 저작권·NVIDIA 파생 코드 고지 및 라이선스 선택
- [x] 현재 배포 후보 트리의 내부 경로·IP·대용량 파일 검사(과거 Git 이력 전체를 점검한 것은 아님)
- [ ] 기존 checkpoint의 외부 배포 권리와 기반 모델 의존성 확인
- [x] 현재 commit 후보의 파일 목록 확인: 기관 미디어·가중치 제외
- [x] 실측 결과·설명용 도식/Action·미완료 기능 구분

현재 코드·문서 전용 개편 브랜치를 업로드했다. 기관 영상·지도·가중치·내부 경로·미공개 측정값은 업로드하지 않는다. 기존 저장소의 공개 범위 설정은 변경하지 않았다. `.gitignore`는 실수 방지 장치일 뿐 공개 승인을 대신하지 않는다. 승인 없이 공개 LICENSE를 임의 부여하지 않는다.
