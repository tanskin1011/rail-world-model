# 공개 전 검토

- [ ] 기존 research 원격을 사용할지 새 저장소를 만들지 결정
- [ ] GitHub 계정 소유·쓰기 권한과 로그인 확인(비밀번호/토큰을 채팅에 전달하지 않음)
- [ ] 우선 private 저장소로 연결
- [ ] 기관 지도·시설·로고·영상·연구 수치의 대외 사용 승인
- [ ] 실사 데이터 원천 라이선스와 재배포 조건 확인
- [ ] 프로젝트 코드의 저작권·NVIDIA 파생 코드 고지 및 라이선스 선택
- [ ] 서버 IP·사용자명·내부 절대경로·자격증명 점검
- [ ] 기존 checkpoint의 외부 배포 권리와 기반 모델 의존성 확인
- [ ] 공개할 commit의 파일 목록 수동 확인
- [ ] 실측 결과·설계 설명·미완료 기능 구분

현재는 로컬 전용이며 원격 push를 하지 않았다. `.gitignore`는 실수 방지 장치일 뿐 공개 승인을 대신하지 않는다. 승인 없이 공개 LICENSE를 임의 부여하지 않는다.
