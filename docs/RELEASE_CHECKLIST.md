# 공개 전 검토

- [x] 기존 Git 이력 보존
- [x] 공개 후보 파일 목록 확인: 코드·문서·선별된 대표 미디어
- [x] 모델 가중치·원본 맵·전체 실사 클립 제외
- [ ] 실사 데이터 원천 라이선스와 재배포 조건 확인
- [ ] 프로젝트 코드의 저작권·NVIDIA 파생 코드 고지 및 라이선스 선택
- [x] 현재 배포 후보의 내부 경로·IP·대용량 파일·문서 링크 검사
- [x] 도달 가능한 과거 Git 이력의 텍스트 blob 패턴 검사: 토큰 형태·개인키 표식·네트워크 주소 검출0건. 일반 홈 경로 예시1건은 기존 upstream 문서 예시로 확인
- [x] 복원한500step 모델용 실행 설정 생성 도구·기존 설정 덮어쓰기 방지 테스트
- [ ] 기존 checkpoint의 외부 배포 권리와 기반 모델 의존성 확인
- [x] 실측 결과·설명용 도식/Action·미완료 기능 구분

대표 미디어의 출처와 권리 범위는 [THIRD_PARTY](../THIRD_PARTY.md)에 정리했다. 체크포인트 외부 배포는 현재 코드·문서 공개와 별도로 검토한다. 저장소 공개 범위 변경과 push는 이 검사에 포함되지 않는다.

과거 이력 검사는 알려진 토큰 패턴과 텍스트 파일을 대상으로 했다. 모델·원천 데이터·전체 실사 클립은 공개 후보에서 제외한다. 소스 코드 라이선스, 실사 입력 출처, 기관 가중치 공개 범위가 정리될 때까지 저장소는 비공개로 유지한다.
